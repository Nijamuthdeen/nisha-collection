# 👗 Nisha Collection — Billing & Inventory System

Production-ready full-stack billing app for a retail clothing shop.
React + Vite | Spring Boot | PostgreSQL (Supabase)

## Features
- Dashboard with today's stats
- Product CRUD + auto barcode generation
- Low stock alerts
- Billing with multi-item cart, barcode search
- CGST + SGST auto-calculation
- Cash / UPI / Card payment modes
- Auto invoice number (NC-DDMMYYYY-0001)
- Stock deduction after sale
- Invoice history + date filter
- Print invoice + Download PDF
- Dark mode UI, fully responsive

## Quick Start
cd backend && mvn spring-boot:run
cd frontend && npm install && npm run dev

See docs/DEPLOYMENT.md for Vercel + Render + Supabase deploy.
